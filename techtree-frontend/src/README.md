# Frontend Source

This directory contains the Angular application code.

## Key entrypoints
- `main.ts` / `app.config.ts`: bootstrapping
- `app/app.ts` & `app/app.html`: root component + layout
- `app/features/graph/`: graph display, data mapping, and UI for editing nodes/edges
- `app/core/services/api/`: API clients

See `docs/FRONTEND_ARCHITECTURE.md` for a detailed structure and migration notes.
